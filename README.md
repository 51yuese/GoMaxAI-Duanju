## 剧本与分集：从故事开始

创建短剧项目后，先确定画面比例、视觉风格、目标集数、时长和默认模型。导入或粘贴已有剧本，结合项目要求整理故事结构、角色、场景与分集内容，再检查拆解结果。

分集剧本可以继续编辑。情节和对白发生变化时，先检查本集文本，再检查它关联的角色、场景和镜头，避免直接重复执行全部生成任务。

## 角色与场景：让镜头共享制作依据

专业短剧以项目资产管理角色、造型、场景、生物与道具。为角色保存描述、参考图和造型，给场景保留视觉设定；确认并锁定必要资产后，再推进本集分析和后续镜头。

这套流程为连续镜头提供共同参考，有助于减少重复描述。**人物和画面的一致性仍受模型、参考素材、提示词与人工筛选影响，不承诺每次生成完全一致。**

## 分镜与声音：按集推进制作

在分集列表中查看每集剧本和制作状态，进入镜头制作时关联角色、造型与场景，按所选模型生成分镜画面和镜头视频。需要调整时回到具体资产或镜头处理，制作结果以实际完成的任务为准。

角色音色、配音与音效集中管理。音色设计、音色克隆、语音合成及视频声音能力根据已接入的服务和授权开放，使用自己拥有相应权利的声音素材。

## 无限画布与导演台：组织镜头关系

无限画布把文字、图片、视频与参考素材放在可延展的空间中，通过节点和连线组织创作过程。可以先探索视觉风格、安排素材关系，再把生成结果用于后续镜头。

导演台用于推敲空间布局、角色位置与视角，为镜头画面准备参考。画布节点工作流与专业短剧是两条相互补充的创作方式，适合不同的工作习惯。

## AI 一键成片：从想法或已有剧本出发

画布成片流程提供**叙事短片、品牌片、知识科普**等入口，支持“描述想法”和“已有剧本”两种起点。带入参考资料和制作要求，选择内容语言、目标时长，以及已配置的策划、绘图和视频模型。

- **逐步确认**：在关键阶段检查和调整内容，再继续制作。
- **智能托管**：按已配置的流程与权限推进任务，仍需满足素材、模型和费用条件。
- **字幕与参数**：根据实际能力启用字幕，按模型开放时长、画幅和其他参数。

“一键成片”指平台组织多个制作步骤，不表示所有模型都支持任意时长，也不表示每次无需审核即可得到可交付影片。

## 时间线与导出：把镜头组织成作品

镜头生成后，在时间线里安排片段、声音和内容顺序，结合预览检查节奏与衔接，再按可用流程输出作品。专业短剧分集制作与画布时间线属于不同入口，选购时可按实际制作路线核对功能。

## AI 图片、视频与大模型中心

短剧制作之外，duanju 包还提供对话、图片、视频和音频等模型入口。图片创作可用于角色探索、场景概念与参考画面；视频创作用于镜头片段和素材制作。比例、清晰度、时长、参考图数量及声音能力随模型与渠道变化。
